# Formacao Java - Modelagem de Dominio

Este repositorio foi criado para estudo de modelagem de dominio, DDD (Domain-Driven Design) e TDD (Test-Driven Development), com foco em evolucao incremental do projeto.

## Estrutura geral

- backend: aplicacao Java com regras de dominio e testes automatizados.
- frontend (em breve): interface para consumo das regras e fluxos da aplicacao.

## Objetivos de estudo

- Modelar o dominio com classes e responsabilidades claras.
- Aplicar conceitos de DDD no desenho da solucao.
- Praticar TDD para garantir comportamento e facilitar refatoracoes.
- Acompanhar qualidade com cobertura de testes.

## Tecnologias atuais

- Java 21
- Maven
- JUnit Jupiter
- Lombok
- JaCoCo

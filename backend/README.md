# Modelagem de Dominio

Projeto criado para estudo pratico de modelagem de dominio, conceitos de DDD (Domain-Driven Design) e TDD (Test-Driven Development), com foco em organizar regras de negocio e validar comportamento com testes automatizados.

## Dependencias principais

- JUnit Jupiter (`org.junit.jupiter:junit-jupiter`) - testes unitarios.
- Lombok (`org.projectlombok:lombok`) - reducao de codigo boilerplate em classes Java.

## Ferramenta de cobertura

- JaCoCo Maven Plugin (`org.jacoco:jacoco-maven-plugin`) - geracao de relatorio de cobertura de testes na fase `verify`.
